作战舱 · 全域座舱 左栏是编队，右面是全集；舱窗外有星流
两级
编队（左栏 · 点）所有舱的并行作业按「需要你 / 运行 / 排队 / 完成」排成一列：类型 / 舱 / 项目 / 正在做什么 / 状态 / 进度。点一行，右边就是它的全集。
作业全集（右面 · 面）概览 / 对接 / 运行 / 变更 / 验收五个页签，同一扇窗里看完，不跳走、不再开第二个窗。
舱籍 · 关联项目
HUD 读数（常驻）「⧉ 账务中台 4 项目」常驻在当前舱的读数位：跟随你筛选的舱、选中的作业所在舱；0 项目时变成「＋ 绑定项目」。点开是舱籍浮层。
舱籍浮层（小面）项目一行一条：org · group / 分支 · HEAD · 最近提交 / 干净还是有改动 / 作业 · 运行 · 工作树 · 消耗。点一行 = 看这个仓库（项目面）；「看全」回舱籍面。
舱籍面（面）一扇窗：ORG 项目分列，每列里是这个项目的仓库状态与作业；本地目录项目在下面一条「建舱时映射」里。点项目名 = 项目面，点作业 = 作业面。没有项目时给空态和「＋ 绑定项目」。
项目面（面）一个仓库的全集：来源（ORG / 本地映射）、仓库路径、远端、分支 / HEAD、最近提交、工作树（按作业开，建舱不预建）、改动、挂在这个项目上的作业与任务。要只看它的作业，点面里的「只看它的作业」。
来源与映射ORG 项目来自 repos/manifest.json；本地目录项目在建舱初始化时映射，只做关联，不克隆、不搬代码、不预建工作树。绑定面板里两张来源分开列。
作业头上的项目签作业面第二行的 ledger 签，点它 = 打开这个仓库；编队行第二行写明「舱 / 项目」，跨舱时不会认错。
场
安静收起面，只剩汐音、任务钟和遥测；编队还在左栏，⌥1 或点任务钟再摊开。
通讯层点汐音立绘 / 点她的气泡 / ⌘K / 点 ticker 都能展开对话，输入框直接拿到焦点；与面并存，可拖可缩可钉住，关掉不丢。
在场汐音立绘随状态换表情；你没在交互、静默到设定的秒数（默认 30s）她就主动来一句，任何键鼠都重新计时。不进 chat、不花 token。
回流模拟回流：attention 落到编队顶部、右上通知窗滑入，背景同时荡开一圈；点消息任意处 = 激活（切到那条作业的面 + 打开对话），Esc 只关消息。
多行草稿⇧⏎ 换行，草稿向上浮成一张编辑层；底栏始终 54px，上面的面不动。Esc 收起但字还在。
舱窗
星流舱窗外是一整片星野：远处的星缓慢漂移，换作业时整片星流加速拉成线——你是在舱里穿过去，不是在看一张表。
跃迁换一条作业自动跃迁一次；⌥W、HUD「⟳ 跃迁」、指令条「跃迁」都能手动来一次；汐音每次反馈也会跃迁并在背景荡开一圈特效。
反馈特效通知还是右上那张简报卡；特效只在背景层：星流拉线 + 三层环 + 扫描带 + 网格脉冲 + 中心柔光 + 四边流光。不遮字、不挡点击。设置里可切「炫 / 标准 / 克制」。
舰桥
心智指令条上方「◇ Opus 5.5 ▾」：换汐音的模型与推理强度。只影响对话，作业里的执行者按各自配置跑。
上下文 / 消耗「◉ 上下文 42%」点开：窗口占比、系统 / 历史 / 工具 / 记忆的构成、本舱按主体的用量；可一键压缩上下文。
汐音设置设置搬到 HUD 的「◐ 汐音」（⌥X）：在场节奏（30s / 90s / 5min / 关）、特效强度、让她说一句、互动一下、表情画廊。点立绘只负责说话。
