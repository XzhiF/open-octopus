# pair · 两个独立页面（舱外 / 舱内）

两个**各自可单独打开**的自包含 HTML，互相用「进舱 →」「◀ 出舱」跳转：

| 文件 | 模式 | 内容 |
|---|---|---|
| `classic.html` | 舱外 · classic | 左栏作战舱 / 任务 / 会话 + chat，和现网同一风格 |
| `cabin.html` | 舱内 · 沉浸 | 汐音立绘 + 编队 tile + 一条指令条 + 顶部三个数字 |

## 舱内默认只有四样东西

1. 汐音（立绘 + 当前状态）
2. 编队：每条并行作业一个圆角 tile（状态点 + 进度环 + 类型图标）
3. 一条指令条：`❯ 下令…`（派发 / 问编队 / 处理待办）
4. 顶部三个数字：运行 / 等你 / 消耗

没有常驻面板、没有文字墙、没有按钮矩阵。

## 按需展开

- 点编队 tile → 右侧滑出**一块**现场：仓库 · 分支 · 状态 · 进度 · 3 行流水 · 一个动作。
- 点 ✉ → 通讯层（汐音 chat）拉开，现场自动收起。
- 「等你 / 受阻」两个小 chip 挂在汐音旁边，点开就是对应作业的现场。
- `Esc`：有面板先关面板，没面板就出舱。

## 出舱 / 进舱

两边都是一次 warp 过渡（约 0.6s）。会话选择与编队状态存在 `sessionStorage`，
出舱再进舱，刚才派的作业还在（`classic.html` 的作战舱行会显示「N 条作业 · M 运行」）。

## 作业类型

`dev` 开发 · `workflow` 工作流 · `wfdev` 工作流开发 · `subagent` 子代理 · `external` 外部 coding agent。
现场按类型给最短信息，不做统一表格。

## 宗旨

chat 本身信息已经很重，舱内只留调度所需；其余一律按需，展开一块、收起一块。
舱内是 cockpit-v5 的收敛版：去掉常驻面板与说明文字，只留角色 + 编队 + 指令条。
