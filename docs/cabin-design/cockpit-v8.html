规则
编队是唯一的索引任务 / 工作流 / 流开发 / 子代理 / 外部 agent 同一行模型，按舱分组，状态与进度一眼分清。
面是「全集」不是 tab概览 / 对接 / 运行 / 变更 / 验收五段同窗铺开；右侧小节导航只做滚动定位。
只在需要时给你需要你的事在编队里带「你」标，右栏常驻三条；点开直接落到对应窗。
回复即操作指令条回一句「通过 / 打回 / 600 / 接管」，汐音落状态；按钮只是兜底。
原型演示：通过 / 打回 / 中止 / 接管 / 拍板会即时改状态；「✦ 模拟回流」会新加一条 attention；「← 返回作战舱」展示入口位置与旧舱面。

数据：编队行复用 GET /api/cabins/:id/jobs（task / workflow / subagent，跨舱聚合）； 五段面按既有读模型拼——cabin_job_events（概览 / 对接）、运行节点与实时流、git diff（变更）、 验收证据（验收）。不引入新的写语义：通过 / 打回 / 中止 / 接管仍回落到一句对话。
