# 指挥舱 v16 — 中央指令核 + 半透明通讯甲板 + 就地回复 + 待处理队列

## 0. 需求原文（用户五条）

1. 取消最底部的输入框。
2. 实际的操作 UI 里要有一个「下指令」的按钮，有很炫的效果，在中间；后面底部半透明，能看到 chat 的历史；还能在新输入框里输入下指令。
3. 如果有反馈回来（像现在有消息来），点击这个消息，直接当场在对应的 chat 中进行回复操作。
4. 整体要有「我在航舰里操作」的感觉。
5. 设计合理的「待我要处理的操作」。

## 1. 一句话

把 v15 的「常驻底栏 composer + 漂浮问答窗」换成：**中央一枚发光的指令核**悬在**半透明通讯甲板**之上；
甲板历史常显、输入行只在激活时出现；回流消息 / 待处理条目 / 编队行**点哪条就就地进哪条 chat 回复**；
右侧一条按优先级排序的「待你处理」队列承载所有要指挥官拍板的事。

## 2. 交互模型

### 2.1 取消常驻底栏（需求 1）
- 没有固定 bottom composer。默认（peek）态甲板只读历史，`#cin` 输入行 `display:none`。
- 输入行只在甲板 `active` 时滑入（`cinIn` 动画），随甲板一起收放。

### 2.2 中央指令核（需求 2）
- `.core`：150px 圆核，三层旋转环（dashed / dotted / arc）+ 轨道粒子 + 呼吸辉光；hover 放大、按下回弹。
- 点击 / `⌘K` / HUD「⌘K 指令」→ `openConsole()`：核爆发一圈 `coreburst` + 跃迁闪 + 音效，甲板升到 `--activeH`，输入行出现并聚焦。
- 激活后核收束成 58px「收起」钮仍悬在甲板上方中央；再点 / `Esc` / 甲板 ✕ 收回 peek。
- 甲板半透明（`backdrop-filter:blur` + 低 alpha 渐变），星野 / 甲板网格 / 历史都透得出来。

### 2.3 就地回复（需求 3）
- 三个入口都走 `openThread(jobId,{decision:true})`：回流简报 `#brief`、待处理卡 `.op`、编队行 `.frow`。
- 切换甲板到该作业线程：标题 / 徽标 / 状态灯 / meta（agent·branch·进度·消耗）随之换；决策卡 `dcard` 内联在消息流里；输入行 placeholder 变成「回复 <agent>…」。
- 决策卡选项点击 / 键盘 `1–9` / 输入框文字命中选项 → `resolveOp()`：原地变「✓ 已处理」回执、队列消项、编队状态推进、汐音确认 + 绿色脉冲 + 确认音。
- 自由文本回复 → relay 给执行分身 + 汐音盯办回执。

### 2.4 航舰感（需求 4）
- 背景：透视甲板网格 + 地平线辉光 + 三团星云 + canvas 星流（单 rAF、DPR≤1.5、跃迁拉线）+ 扫描带 + 漂浮粒子 + 四角框景。
- HUD：任务钟（秒级）、运行中 / 需要你 / 编队 / 消耗读数；舰桥中上大字钟 + 四弧读数。
- 音效：WebAudio 合成舰桥低鸣（55/82.4Hz + 空气噪声）常驻；send / arrive / confirm / open / warp 各有效果音；HUD「音效开/关」一键总闸（`⌥M`），默认开、首次手势解锁。
- 文案全程舰桥语汇：指挥官 / 编队 / 回流 / 拍板 / 验收 / 消项 / 跃迁。

### 2.5 待处理队列（需求 5）
- 右栏 `.ops`：`block(红) > decide(青) > accept(绿) > confirm(琥珀)` 优先级排序，可切「最新」。
- 每条：handle · 类型 chip · 时效 · 标题 · 上下文 · 问题框 · 「✓ 推荐」一键拍板 · 「进入对话 →」。
- 答完原地回执 2.6s 后折叠消项；空队列显示「✓ 全舱无待办」。
- 回流 `arriveNext()`：从 pool 取一条 → 作业转 wait/blocked、线程补一句、队列插卡、顶部简报 + 四边流光 + 跃迁 + 提示音 + 汐音表情台词；16s 首条自动、之后 34s 间隔、HUD「✦ 模拟回流」手动。

## 3. 布局与响应式

- 桌面：左编队 268 / 中 arena / 右待处理 296；甲板夹在汐音舱位与待处理之间，指令核悬甲板上方中央。
- ≤1180：待处理收为右抽屉（HUD「◈ 待处理」+ 计数徽标）；`.stage` 解除自身堆叠上下文，抽屉 z80 压过 scrim z78。
- ≤860：编队收为左抽屉（HUD ☰）；汐音舱位隐藏；甲板 / 核 / 简报全宽；核缩 120px。
- 抽屉 scrim 在 `.app` 内（z78），点空白关闭；`Esc` 优先关抽屉 → 简报 → 甲板。
- 全局 `[hidden]{display:none!important}` 保证 back / close / meta 的隐藏态不被 display 规则覆盖。

## 4. 验收（_verify-v16.mjs 实测）

- peek 无输入行、历史可见、back/close/meta 隐藏；无横向溢出（三档视口）。
- 核点击 → 输入行出现 / 甲板 active / 核 compact / expand 隐藏 / close 可见。
- 主对话下指令 → 消息入流 + 新作业进编队；Esc 收起。
- 待处理卡 → 线程切换 + 内联决策卡 + 回复输入；选项拍板 → 队列消项 + 回执 + 计数递减；推荐一键拍板同效。
- 模拟回流 → 简报出现；点简报 → 就地进线程带决策卡与输入。
- 音效开关 / 换色 / 点立绘开_console / 反复开合不损坏消息流。
- 移动：抽屉开合、输入行在视口内、发送可用、编队行开线程；平板无溢出。
- 全程 0 console / pageerror。

## 5. 与 v15 的关系 / 非目标

- 继承 v15 的色调 token、星野 / 跃迁 / 四边流光、汐音立绘与表情、编队语义；**替换**底栏 composer 与漂浮问答窗为「指令核 + 甲板 + 内联决策卡」。
- 非目标：作业五页签全集面（v16 聚焦指挥与回复，细节面留待后续）、问答窗多开拖拽（改为单甲板就地）、服务端决策账本对接（原型 mock）。
