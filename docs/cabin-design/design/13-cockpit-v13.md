## 1.5 铁律：布局恒定（一高一低是禁区）

> 2026-11-15 用户原话：「我就是要避免一高一低的动作，像展开对话，然后上面整体一低一高，
> 这个犯了最致命的错。」

这条优先级高于本稿其它所有美观取舍：**任何开关、弹层、消息、草稿都不能改变舱面与底栏的几何**。

### 什么算「一高一低」

- 打开 / 关闭对话，`#arena` 或面跟着变高变矮（半个像素都不行）；
- 打开 / 关闭草稿，底栏 54px 变成 80px、或 ticker / 舰桥被挤走；
- 消息、广播、设置出现时把内容往下推；
- 立绘、编队、面的任何一次重排。

### 怎么做到

| 层 | 定位 | 对布局的影响 |
|---|---|---|
| 对话浮窗 | `position:fixed` | 无（拖动 / 缩放只改自己的 rect） |
| 多行草稿 | `position:fixed`，几何由底栏 rect 算出 | 无 |
| 通知窗（简报卡）/ 背景特效层 | `position:fixed` / `absolute` | 无（特效层 `pointer-events:none`） |
| 汐音设置 / 舰桥浮层 | `position:fixed`，贴按钮 | 无 |
| 点击反馈（星光 / 涟漪） | `absolute`，舱体内 / `inset:0` | 无（`pointer-events:none`） |
| 编队抽屉（≤1120） | `position:fixed` | 无 |

**底栏三行（ticker / 舰桥 / 指令条）在任何状态下都保持同一高度。**
对话展开时 ticker **不收起**，只换内容与状态：
`展开对话 ⌄` → `对话已展开`，边框亮一档；关闭时换回。
（v12 原型里 `openComms()` 会 `ticker.classList.add('hide')` → 面从 692 长到 730、
立绘整体下移 38px——这正是本次要拆掉的。）

### 验收（机器可判）

在 1440×900 下依次进入：初始 → 开对话 → 关对话 → 开设置 → 开草稿 → 广播，
每一步量 `#arena` / `.cmd` / `#box` / 立绘 的 `getBoundingClientRect()`，
**必须逐项完全相等**。原型已按这条验过（`#arena` 恒为 `[336,60,1084,692]`，
`.cmd` 恒为 `[752,148]`）。

> 实现侧注意：`CockpitChatWindow` 的默认几何只用 `arena` 量一次；**不要**再因为
> 「ticker 收起」去重算（现在的实现里 ticker 不会收起，那段 rAF 重算可以直接删掉）。

| 你做的事 | 发生什么 | 备注 |
|---|---|---|
| 点汐音立绘 | 打开对话浮窗 + 聚焦输入框；她是关着的就补一句「我在。」 | 与 classic 同义 |
| 点她的漫画气泡 | 同上 | 气泡不再只是装饰 |
| 点底部 ticker | 同上（v12 已有） | 保持不变 |
| `⌘K` / 聚焦输入框 | 同上（v12 已有） | 保持不变 |
| 点 HUD `◐ 汐音` | 打开**汐音设置**浮层（不是对话） | 新的设置唯一入口 |

立绘 hover **不再有任何提示**（v13.1 去掉了「⏎ 说话」悬浮字与原生 tooltip —— 点下去就有反馈，
不需要再教一次）；点击语义不变。

### 2.2 汐音设置浮层（HUD 右侧）

```
┌ 汐音 · XIYIN-07 ────────────────────── ✕ ┐
│ ◉ 在场    [关闭] [30s] [90s] [5min]        │
│    没在交互时按这个节奏主动说一句；动一下键鼠就重新计时
│ ✦ 特效    [炫] [标准] [克制]              │
│ ✦ 现在    [让她说一句]  [互动一下]        │
│ 表情  ◻ ◻ ◻ ◻ ◻ ◻ ◻                      │
│ 声效 [开]   静默 [30 分]                   │
│ 点立绘 = 直接跟她说话                      │
└────────────────────────────────────────────┘
```

规则：

- 浮层**贴住 HUD 按钮**向左下展开，宽 344；点外部 / `Esc` 即收。
- 它取代 v12 的「点立绘弹控制条」——**立绘不再承载设置**。
- 所有项都写进 `CockpitPrefs`（持久化到 cabin），不是本次会话的临时值。
- 「互动一下」保留：换表情 + 一颗心 + 一句随机反应，但它不再是进入对话的唯一方式。

### 2.3 被取代的 v12 规则

- ~~点立绘弹出控制条（说一句 / 互动 / 表情画廊 / 在场频率）~~ → 立绘 = 说话；设置进 HUD。
- 其余 v12 规则（对话是浮窗、换面不关窗、Esc 栈、舰桥三浮层）保持不变。

### 2.4 点击的第一拍：即时反馈（v13.1）

> 用户原话（同日）：classic 里点一下角色她**立马**有反馈，全域座舱也要这样。

v13 第一版「点立绘 = 开对话窗 + 聚焦」只有功能性反馈，手上没感觉。v13.1 把 classic
的点击手感搬过来，并且在**同一拍**里完成，不等开窗：

| 顺序 | 反馈 | 时长 | 说明 |
|---|---|---|---|
| ① | 表情换图 | 立即，hold 3.6–5s | 首点 `wink`（俏皮），之后跟着台词的情绪走 |
| ② | 立绘上浮星光 ×6 | 0.85s | 舱体内，`overflow:hidden` 裁边；连点只留最近 18 颗 |
| ③ | 一圈边框涟漪 | 0.52s | 舱体外 1px 边框向外淡出（scale 1 → 1.045） |
| ④ | 点击音 | — | `blip(920)`；「互动一下」才用 chime |
| ⑤ | 台词气泡 | 打字机 22ms/字 | 首点「**我在。你说。**」；之后按 `XY_LINES` 顺序轮播（不随机，连点不重样） |
| ⑥ | 全仓一拍 | 一拍 | `fx.edge` 四边流光；特效「炫」档再加 `fx.feedback(..., 'lite')` 背景扫描/环 |
| ⑦ | 打开对话窗 + 聚焦输入框 | 同拍 | 这是正事，但排在反馈**之后**申请 |

规则要说清的几条：

- **节流 900ms**：这段时间内的连点只重复 ②③④（手感），**不重开打字机、不重复台词**，
  否则连点会看到字一闪一闪地从头打。过了 900ms 才算新的一句。
- **首句 vs 轮播**：点之前对话窗是关的 → 招呼句；已经是开着的（你在跟她说话）→ 轮播词库。
- **气泡就一个**：点击台词和在场的主动搭话共用同一个气泡；后到的覆盖先到的（跟 v12 一致）。
- **不进 ticker**：点击台词是「对答」，ticker 只放「收到的消息」（在场 / 回流 / 阻塞），
  免得你打字时消息位被一句「我在」顶掉。在场的主动搭话照旧进 ticker。
- **reduced-motion**：星光 / 涟漪不出，气泡直接出全文。
- **布局**：星光在舱体内、涟漪 `inset:0`，全是 `position:absolute; pointer-events:none`，
  `.ck12-crew` 的 `344 × min(60vh,548)` 与舱面 rect 一键不变（§1.5 铁律）。

## 3. 在场：从「随机间隔」改成「静默计时 30s」

### 3.1 计时规则

```
dueAt = lastInteractionAt + gap
lastInteractionAt = 最近一次 pointerdown / keydown / 发送 / 切面
```

- 到点 → 过闸门 → 开口 → 重新计时（`dueAt = now + gap`）。
- 任何交互（含鼠标划过不算，按下才算）都把 `dueAt` 推后。
- 舰桥上直接显示倒计时：`◉ 在场 · 12s`，到点变 `◉ 在场 · 开口中`，然后归零重计。

### 3.2 档位（替换 `PRESENCE_RATES`）

| 档 | gap | 说明 |
|---|---|---|
| 活跃（默认） | **30s** | 用户明确要的节奏 |
| 标准 | 90s | 不吵但不冷场 |
| 安静 | 5min | 只在真有事实时说 |
| 关闭 | — | 回流/阻塞照常举牌，只是不闲聊 |

> 生产值就是秒级，不再乘 60。原型与实现都用这一张表。
> 兼容：旧 prefs 里的 `presenceRate: 'quiet' | 'std' | 'active'` 直接映射到新表，不迁移。

### 3.3 闸门（保留 v12 的，调整一条）

| 闸门 | 行为 |
|---|---|
| 页面隐藏 | 不说，20s 后再试 |
| 汐音正在流式回复 | 不说，15s 后再试 |
| 草稿里**正在打字且有内容** | 不说，15s 后再试（清空草稿即解除） |
| 任一弹层未收（模式说明 / 返回舱确认 / 设置浮层 / 草稿浮层 / 立绘气泡） | 不说 |
| 22:00–08:00 | 不说（免打扰） |
| ~~对话浮窗开着~~ | **不再拦**。开着也照说，但只走克制档特效（见 §5.4），不抢焦点 |

### 3.4 说什么（事实优先，沿用 `xiyin-scene` 的话术表）

1. 需要你（等验收 / 待回答 / 阻塞）→ 带作业名 + 指向具体页签；
2. 运行中 → 报进度，不要求动作；
3. 回流队列 → 报条数；
4. 都没有 → 一句闲聊（第 3 次夹一条，避免复读）。

**不进 chat、不花 token**（v12 规则保留）。

## 4. 多行草稿：悬浮 sheet，不改排版

### 4.1 为什么不是「输入框自己长高」

底栏 54px 是舰桥的一部分；`textarea` 长高会把 ticker、舰桥仪表条、整个面往上顶，
每一行都会触发一次重排——正是用户说的「影响排版」。

所以：**底栏永远 54px；多行编辑搬到一张浮起来的草稿浮层里。**

### 4.2 交互

| 操作 | 结果 |
|---|---|
| `⇧⏎` / `⌥⏎` | 插入换行 → 草稿浮层自动展开（首次） |
| 直接粘贴含换行的文本 | 同上 |
| `⏎` | 发送（保持 v12） |
| `Esc` | 收起草稿浮层，**不丢字**；焦点回到原来的行 |
| 点浮层外部 | 不收起（避免误丢焦点）；只有 Esc / 发送会收 |
| 发送后 | 浮层关闭、底栏清空、回到 54px |
| 草稿超过 8 行 | 浮层内部滚动，浮层最高 42vh |
| 草稿浮层展开时点底栏 | 把焦点送回浮层里的同一个编辑器 |

### 4.3 几何与视觉

```
┌ 面（不动）────────────────────────────────┐
│                                           │
├───────────────────────────────────────────┤
│ ╭ 草稿 · 4 行 ──────── ⇧⏎ 换行 · ⏎ 发送 ╮ │  ← 浮层，向上展开 180ms
│ │ 第一行…                                 │ │     position:absolute; bottom:calc(100% + 8px)
│ │ 第二行…                                 │ │     宽 = 底栏，最高 42vh，超出滚动
│ │ ▸                                       │ │
│ ╰─────────────────────────────────────────╯ │
│ 汐音 · 一句回执 ………               展开对话 ⌄ │  ← 被浮层盖住（不位移）
│ ◇ Opus 5.5 ▾ │ ◉ 42% │ ↑12.4k ↓3.1k │ ¥1.28 │
│ ❯ 第一行…                        ▤ 4 行  ⏎ │  ← 底栏原地，只换内容
└───────────────────────────────────────────┘
```

- 浮层与底栏同一条舱窗边线（`--a` 30%），圆角 14，毛玻璃 16px。
- 底栏在草稿态显示**首行预览 + `▤ N 行`**，点击即把焦点送回浮层。
- 编辑器 DOM 只有一个（移动到浮层 / 移回底栏），不复制、不失焦、不丢选区。
- `prefers-reduced-motion` 下取消展开动画。

### 4.4 实现口径

- 现在 `ChatArea` 的 TUI composer 已有 `⌥⏎ = 换行`；v13 补 `⇧⏎ = 换行`，并把 `⏎` 留给发送。
- 底栏的 composer 是 portal 槽（`chat-slots.ts`）；草稿浮层是**同一个 textarea 的第二个槽**：
  `composer` / `composer-expanded` 两个槽，按 `draftMode` 切换挂点。
- 不给 ChatPane 加第二套发送管线——`submit()` 仍是唯一出口。

## 5. 反馈：通知窗 + 背景特效（不做全屏接管）

> 2026-11-15 追加口径（推翻了本稿第一版的「全屏广播」）：
> 「你这个遮挡全屏幕的通知特效太浮夸了，我倾向于，现在的通知窗，加背景的特效。」

**结论：通知永远只是一张窗（右上简报卡 / 立绘气泡 / ticker），
特效全部铺在背景与边缘，不遮内容、不接管点击、不弹大字。**

### 5.1 什么时候出什么

| 触发 | 通知窗 | 背景特效 | 时长 |
|---|---|---|---|
| attention 到达（回流 / 等你 / 阻塞） | 右上简报卡 | **炫**（全开） | 2.4s |
| 汐音主动反馈且带作业指向 | 右上简报卡 | **炫** | 2.4s |
| 汐音主动反馈（闲聊 / 报进度） | 气泡 + ticker | **克制**（只光晕 + 环） | 1.5s |
| 你正在输入 / 草稿开着 | 只 ticker | 不出 | — |
| 你点「让她说一句」 | 气泡 + ticker | 克制 | 1.5s |

**没有任何一层会挡住面、糊字或接收全屏点击。**
点击只发生在窗口上（见 §6）。

### 5.2 特效分层（都取当前色调 `--a` / `--b` / 事件色）

| 层 | 位置 | 内容 |
|---|---|---|
| 背景 canvas | z0 | **跃迁星流**：星点拉成拖尾线，300ms 内加速再回落（v12 已有） |
| `#bgfx`（背景层 z1） | 内容之下 | **扫描带** 30vh 自上而下（1.35s）；**网格脉冲**：地面网格亮一档再灭（1.9s） |
| `#bgfxTop`（内容之上 z3，`mix-blend-mode:screen`） | 只提亮、不发糊 | **柔光脉冲**：从中心荡开的一层淡色调（1.7s）；**跃迁环 ×3**：1.5px 细线，错峰 0.22s 扩出（1.75s） |
| `#fx` / `#edgefx`（v12 已有） | 中心 / 四边 | **中心柔光** + **四边流光** |

- `screen` 叠加只做提亮：文字、按钮、面板都保持可读，点击穿透（全层 `pointer-events:none`）。
- 环的峰值透明度 1、38% 时回落到 0.62、末段淡出——看得见但不刺眼。
- `prefers-reduced-motion` 下：不出环 / 扫描 / 网格，只留四边流光与一次静态柔光。

### 5.3 「穿梭」到底怎么触发（写死这张表）

| 入口 | 说明 |
|---|---|
| `⌥W` | 手动跃迁（v12 已有） |
| HUD `⟳ 跃迁` | **新增**，界面上可见的入口 |
| 指令条 chip `⌥W 跃迁` | v12 已有 |
| 换面（点编队另一条） | 小幅跃迁（v12 已有） |
| 换色调 | 跃迁 + 一圈脉冲（v12 已有） |
| **任一反馈到达** | 跃迁加速一档（v13 新增，不再有任何遮罩） |
| 指令说「跃迁」 | v12 已有 |

### 5.4 特效强度（设置里三档）

`炫（默认） / 标准 / 克制`，写进 prefs：

- **炫**：带作业指向的反馈 → 全部背景特效；闲聊 → 光晕 + 环；
- **标准**：只有 attention 到达才全开，其余只留边缘流光（通知窗不受影响）；
- **克制**：通知窗照常出现，特效只留四边流光（不铺背景层）。

## 6. 消息窗：Esc 关、点任意处激活

### 6.1 三种消息窗

| 窗 | 内容 | 谁产生 |
|---|---|---|
| 右上简报卡 | 标题 + 一句原因 + 目标，340px，10s 自动收 | attention 到达 / 带作业指向的主动反馈 |
| 立绘气泡 + ticker | 一句短话 | 闲聊 / 报进度 |
| 聊天里的卡片 | 事件卡（可点开作业） | v12 已有 |

**没有全屏窗。** 特效层不接收事件（`pointer-events:none`），只有简报卡可点。

### 6.2 Esc 顺序（唯一栈，从高到低）

```
草稿浮层 → 舰桥浮层(65) → 汐音设置(66) → 简报卡(40) → 模式说明(80)
→ 返回舱确认 → 编队抽屉 → 对话浮窗(60) → 作业面
```

> 实际优先级按 `CockpitLayerStack` 的 priority 排；广播必须比对话浮窗高，因为它盖在它上面。

### 6.3 点击语义

| 你点的地方 | 结果 |
|---|---|
| 简报卡任意处 | **激活**目标：切到该作业面（带页签）+ 打开对话 + 编队行高亮 2.4s；卡收起 |
| 聊天事件卡 | v12 行为：打开作业面 |
| 广播/卡片的空白外区域 | 不收（避免误触）；只有 Esc / 自动收 |

**「激活他所有的窗口」的读法**：一张消息通常只指向**一条作业**，激活 = 把这条作业
需要的窗口一起摆出来（作业面 + 对话 + 编队高亮）；消息没有作业指向时，激活 =
打开对话窗并聚焦。**不是**把所有历史消息的窗口都打开——那会把屏幕糊满，
与 v12「点 → 面，不糊屏」的规矩冲突。若以后要「全部展开」，进待定。

### 6.4 文案改动

- 简报底部 `已进编队 · 不用点` → **`点开现场 · Esc 关闭`**。
- 简报卡鼠标变成 `pointer`，hover 时整卡描边亮一档。
- v12 的「不要求当场点」仍然成立：不点也会在 10s 后收进编队/聊天，只是现在点了更快。

## 9. 验收口径（做保真实现时照这个验）

0. **布局恒定（先验这条）**：初始 → 开对话 → 关对话 → 开设置 → 开草稿 → 广播，
   每步量 `#arena` / `.cmd` / `#box` / 立绘的 rect，逐项必须完全相等；
   底栏三行高度不变，ticker 不收起（只换文案）。
1. **点立绘**：1 次点击 → `textarea` 拿到焦点；`cockpit-crew-menu` 测试 id 不再存在。
2. **设置可达**：HUD `◐ 汐音` 打开设置；改「在场 30s」后 prefs PATCH 一次成功。
3. **静默计时**：把当前时间推进 29s → 不开口；再推进 1s → 开口一次；期间点一下鼠标 → 计时归零。
4. **多行**：连按 3 次 `⇧⏎` → 草稿浮层出现，`#sceneHost` 与底栏的 `getBoundingClientRect()` 前后一致；
   `Esc` 收起且草稿还在；`⏎` 发送后浮层消失。
5. **反馈特效**：注入一条 attention → 简报卡立刻出现；`.ck12-bgfx` 进入 `run`（背景扫描 + 网格脉冲），
   `.ck12-bgfx-top` 出现环与柔光；2400ms 后全部收掉。
   **任意时刻都不得存在全屏遮罩层**（`.ck12-bcast` 不应存在），内容区点击不被拦截；
   `prefers-reduced-motion` 下只有四边流光 + 一次静态柔光。
6. **Esc 顺序**：广播打开时按 Esc 只收广播，第二次收简报，第三次收对话，第四次收面。
7. **点击激活**：点广播 → 作业面切到该 job 的指定页签 + 对话窗打开 + 编队行 `is-activated`；
   点无 job 的消息 → 只开对话。
8. **不动别人**：classic 的全部 E2E 与 `cockpit-global.spec.ts` 原 11 条保持绿。

## 10. 与 v12 的冲突（明确被取代）

| v12 规则 | v13 |
|---|---|
| 点立绘 → 控制条（说一句 / 互动 / 表情 / 频率） | 点立绘 → 说话；设置进 HUD |
| 在场 = 随机间隔（分钟级，12–24 / 6–16 / 3–8） | 在场 = 静默计时（30s / 90s / 5min） |
| 来消息「只报信、没有按钮、不用点」 | 仍然不用点，但**点 = 激活**；文案从「不用点」改为「点开现场」 |

| 特效只有星流 / 环 / 彗星 / 脉冲 / 边缘流光 | 分层背景特效（§5.2）+ 特效强度三档（炫 / 标准 / 克制） |

## 11. 待定

- 「点消息 = 激活所有窗口」是否要扩大成「把所有待处理消息的目标一起排开」——当前按「一条消息一组窗口」实现。
- 汐音设置里是否要「按舱覆盖」（现在 prefs 是舱级，但全域是跨舱视图，写哪个舱要定）。
- 30s 是否太频繁：可先上「活跃 30s」，观察一周再调默认档。
- 反馈特效是否要出声（现在只有 WebAudio 轻响，受 `sound` 开关约束）。
- 多行草稿是否要支持 `⌘⏎` 单独发送、以及草稿跨页签保留。
