# 10 · 两种模式：工作台 / 工作舱

> 设计判断：原系统只有**任务**和**会话**两个原语；一个长期的、指定的 CWD 就是一个舱。
> v6 把项目、运行、任务、会话、Trace 都摆成了并列层，看起来全，实际上找不到关注点。
> 这一版先收口领域，再分两种模式：**默认工作台**（日常）与**沉浸工作舱**（指挥）。

原型：

- `../index-v2.html` — **工作台 · 默认版**：左栏「等你 / 任务 / 会话」+ 主区任务页 + 底部指令条。
- `../cockpit-v7.html` — **工作舱 · 沉浸版**：注意力栏 + 立绘 + 任务工作台（镜头）+ 全舱 Trace。
- 两个文件共用同一份 mock 数据、同一套状态与动作词汇，可通过 URL hash 双向切换。

---

## 一、先收口：一个舱 = 一个 CWD

```
Cabin  ~/projects/ledger（长期项目 · 一个指定 CWD）
├─ Task ─┬─ art   绘画：版本 / 素材 / 交付
│        └─ dev   开发 ─┬─ workflow  有工作流：运行 / 变更 / Trace
│                       └─ direct    直做：会话 / 变更 / Trace
├─ Session        执行现场；一个任务可挂多个（实现 / 归档 / 复核）
├─ Attention      由任务 / 会话派生：验收 / 选稿 / 阻塞（不是新实体）
└─ Ledger         Trace + 消耗：汐音 → Agent → 工作流，按主体分列
```

三条收口：

1. **舱内不再有「项目」维度。** 多项目 = 平台上的多个 cabin；一个舱只对应一个 CWD。
   这样任务、会话、工作树、消耗都有唯一归属，不再出现「这个任务属于哪个项目」的心智负担。
2. **运行 / 变更 / Trace 不再是顶层对象。** 它们是**任务里的镜头**；会话是执行现场。
   顶层只保留：任务、会话、等你。Trace 保留一个全舱审计入口（只读）。
3. **注意力不是列表。** 它是任务上的一个标记，由「等你验收 / 等你选稿 / 阻塞」派生；
   左栏/注意力栏只显示需要人的，不复制任务列表。

## 二、两种模式的定位

| | 工作台 `index-v2` | 工作舱 `cockpit-v7` |
|---|---|---|
| 定位 | 日常默认，替代原来的多浮窗首页 | 沉浸指挥，完全体 |
| 构图 | 左栏（等你 / 任务 / 会话）+ 主区 + 指令条 | 注意力栏 + 立绘 + 内容区 + 指令条 |
| 浮窗 | 无 | 无（一次只开一个内容层） |
| 任务 | 任务页 + 镜头栏 | 任务工作台 + 镜头栏 |
| 助手 | 底部指令条 + 一行 ticker | 立绘 + 气泡 + 通讯层 + ticker |
| 皮肤 | 基础暗色 | 休伯利安 / 净黑终端 / 赤鸢 / 月光王座 |
| 切换 | 「进入工作舱 →」 | 「← 工作台」 |

### 工作台（默认版）

```
┌──────────────────────────────────────────────────────────────────────┐
│ ⬢ ledger  ~/projects/ledger  5 任务 · 7 会话 · ¥1.28   Trace  进入工作舱 → │
├───────────────┬──────────────────────────────────────────────────────┤
│ 等你 3        │  M2 · 结算对账   开发 · 工作流   待验收               │
│ ● M2 验收     │  fix/reconcile · ¥0.42 · 78%                          │
│ ● A1 选稿     │  [概览] [运行] [变更] [Trace]                         │
│ ● M1 阻塞     │                                                      │
│               │  改动 / diff / 校验 / 结论                            │
│ 任务 全部 绘画 开发                                                  │
│ ▸ M2 结算对账 │                                                      │
│ ▸ A1 主视觉   │                                                      │
│ ▸ M1 退款链路 │                                                      │
│ ▸ D1 依赖升级 │                                                      │
│               │                                                      │
│ 会话 7        │                                                      │
│ ● 汐音 / ledger-2 / art-1 …                                          │
├───────────────┴──────────────────────────────────────────────────────┤
│ 汐音：M2 等你验收；A1 出了 4 版。                                      │
│ ❯ 跟汐音说：看 A1 的第 3 版 / 通过 / 退回 …                            │
└──────────────────────────────────────────────────────────────────────┘
```

- 没有浮窗、没有 dock、没有 17 宫格。所有内容在主区以**任务页**展开。
- 任务页的镜头栏是明确的（默认版可以让人看见全部镜头）；镜头内容不弹窗。
- 会话是独立视图（transcript），从任务或左栏进入；底部指令条始终是汐音。

### 工作舱（沉浸版）

```
┌──────────────────────────────────────────────────────────────────────┐
│ ⬢ 工作舱  ~/projects/ledger  2 在跑 3 需要你 6 分身 ¥1.28  ◐皮肤 工作台 │
├────────────┬─────────────────────────────────────────────────────────┤
│ 等你 3     │  ← 任务舱 / M2 · 结算对账     [会话] [Trace]             │
│ ● M2 验收  │  开发 · 工作流 · spec-dev  待验收  ¥0.42 · 12m          │
│ ● A1 选稿  │  [概览] [运行] [变更] [Trace]                           │
│ ● M1 阻塞  │  ┌──────────────┬───────────────┐                       │
│            │  │ 改动          │ diff          │     立绘 344×540      │
│  立绘      │  ├──────────────┼───────────────┤     始终原尺寸        │
│            │  │ 校验          │ 结论 / 通过   │                       │
│            │  └──────────────┴───────────────┘                       │
├────────────┴─────────────────────────────────────────────────────────┤
│ 汐音：M2 等你验收 · 点「变更」看证据，或直接说「通过 / 退回」           │
│ ❯ 回汐音一句…                                    [⌥1 任务舱] [⌥2 Trace] │
└──────────────────────────────────────────────────────────────────────┘
```

- 任务工作台占据立绘右侧的同一块内容区；通讯层与任务工作台互斥。
- 任务舱（deck）只有三块：**任务 / 等你 / 会话**，不再有项目条和运行列表。
- 全舱 Trace 仍是独立只读场景：座舱拓扑 + 交互流 + 按主体消耗。
- 皮肤只换 UI 强调色，不换数据、不换布局、不换立绘。

## 三、任务镜头：把「层」收成「问题」

| 任务类型 | 镜头 | 每个镜头回答的问题 |
|---|---|---|
| 绘画（art） | 概览 / 版本 / 素材 / 交付 | 这一单要什么 / 哪版最稳 / 用了哪些参考 / 出片到哪 |
| 开发 · 工作流 | 概览 / 运行 / 变更 / Trace | 做到哪步 / 节点在干什么 / 改了哪些文件 / 谁和谁交互、钱花在哪 |
| 开发 · 直做 | 概览 / 会话 / 变更 / Trace | 做到哪步 / 现场在干什么 / 改了什么 / 谁和谁交互 |

镜头不是并排的场景，也不是目录：

1. **默认由汐音选。** 注意力卡直接绑定镜头：M2 验收 → 变更；A1 选稿 → 版本；M1 阻塞 → 运行。
2. **人也可以切。** 镜头栏始终在任务页顶部（默认版可见全部；沉浸版同样可见，作为兜底）。
3. **说一句也能切。** 「看运行」「看变更」「看 Trace」「看第 3 版」都在当前任务内切镜头；
   「看 A1 版本」会先切任务再切镜头。
4. **不会新增层。** 镜头里不再弹窗、不再开第二个抽屉；证据、diff、日志都在当前镜头里。

## 四、助手如何触发关注

- **唯一入口**：汐音（通讯层 / 指令条 / 立绘气泡）；分身只作为执行体汇报，不作为对话对象。
- **注意力 → 任务 + 镜头**：左栏卡片不是「打开一个面板」，而是「打开这个任务的某个镜头」。
- **一句话落动作**：
  - 通过 / 退回 → M2 验收（卡置灰、注意力移除、任务状态更新）
  - 选第 3 版 → A1 选稿（版本切换、注意力移除、状态变「已选稿」）
  - rebase 再跑 / 回滚 → M1 排障（运行节点落状态、Trace 主体状态同步）
  - 接管 / 暂停 → 会话
- 面板里的按钮一律是**兜底**：在沉浸版带「兜底」前缀 + 主操作「推荐」圈；
  在默认版是普通按钮，但词汇与 chat 完全一致。

## 五、两种模式共享什么

| 共享 | 说明 |
|---|---|
| 数据 | `CABIN / TASKS / SESSIONS / ATTENTION / TRACE / USAGE` 同 schema、同 mock |
| 状态 | 任务状态、镜头集合、注意力派生、会话状态 |
| 动作词汇 | 通过、退回、选第 N 版、rebase 再跑、回滚、接管、暂停、看 Trace |
| 任务镜头 | 三种任务类型的镜头集合一致 |
| Trace / 消耗 | 同一拓扑、同一事件口径、同一防双算说明 |
| 模式切换 | URL hash：`#task=m2&lens=changes`、`#session=s-42`、`#view=trace` |
| 后端读模型 | `view.attention / workflows / tasks`、`agent/sessions/running`、`cabin_job_events`、`llm_calls`、`subagent_runs` |

**只在沉浸版有：** 立绘、气泡、注意力栏、皮肤、Ticker 的未读脉冲。
**只在默认版有：** 完整左栏（任务 + 会话同屏）、无立绘的紧凑任务页。

### 切换契约

```
index-v2.html#task=m2&lens=changes   ⇄   cockpit-v7.html#task=m2&lens=changes
index-v2.html#session=s-42           ⇄   cockpit-v7.html（会话场景）
index-v2.html#view=trace             ⇄   cockpit-v7.html（全舱 Trace）
```

- 切模式不丢当前任务 / 镜头 / 会话；两边都读 hash。
- 从沉浸版回工作台时，若当前在全舱 Trace / 会话，也保留对应视图。

## 六、与 v6 / index 的关系

| 版本 | 角色 | 去留 |
|---|---|---|
| `index.html` | P1–P5 落地稿：17 模块 / dock / 多浮窗 | 保留作历史，不采用 |
| `index-v2.html` | 默认工作台重做：任务 + 会话，无浮窗 | **采用为默认版** |
| `cockpit-v1…v5` | 驾座构图 / 通讯层 / 回复即操作的演进 | 保留作参考 |
| `cockpit-v6.html` | 作业仓的完全展开：项目 × 运行 × 任务 × 会话 + 5 个作业面 | 保留作对照，层偏多 |
| `cockpit-v7.html` | 收口版：一个 CWD、任务 / 会话两原语、任务镜头 + 全舱 Trace | **采用为沉浸版** |

v7 相对 v6 去掉的层：

- 项目条 / 项目筛选（一个舱一个 CWD）
- 运行 / 任务 / 变更 / 会话四个并列下钻（收进任务镜头）
- 指挥台的「执行中 · 工作流」列表（运行是任务的镜头）
- 四块并列的作业面板（任务 / 等你 / 会话三块足够）

## 七、验证点

**工作台（index-v2，1440×900）**

1. 打开落在 M2 任务页；左栏 3 张等你、5 个任务、7 个会话；镜头为 概览/运行/变更/Trace。
2. 任务分类筛选：绘画 → A1 / A2；开发 → M2 / M1 / D1。
3. 点 A1 → 版本镜头，4 张大图加载成功；点任一版切换当前版。
4. 点会话 → transcript；底部指令条可继续对会话说话。
5. `Trace` → 全舱拓扑（9 节点 / 16 事件 / 7 主体消耗），点节点过滤。
6. 输入「看 A1 版本」→ A1 + 版本；输入「通过」→ M2 验收落状态。
7. 「进入工作舱 →」→ `cockpit-v7.html#task=…&lens=…`。

**工作舱（cockpit-v7，1440×900）**

1. 打开落在 M2 的变更镜头；注意力栏 3 张；HUD 2 在跑 / 3 需要你 / 6 分身 / ¥1.28。
2. 切镜头：概览 / 运行 / 变更 / Trace 内容正确；运行镜头点节点切换流。
3. 任务舱：任务分「开发 3 / 绘画 2」，等你 3，会话 6。
4. A1 → 版本镜头，4 张大图；说「选第 3 版」→ 已选稿、注意力移除。
5. M1 → 运行镜头；「rebase 再跑」→ 节点回到运行、注意力移除、Trace 主体同步。
6. 会话 → transcript；「接管」→ 你接管。
7. 全舱 Trace：9 节点 / 16 事件 / 7 主体消耗；点节点过滤；消耗脚注完整可见。
8. 皮肤按钮循环 4 套，布局与立绘不变。
9. 「← 工作台」→ index-v2 且保留任务/镜头；index-v2 再「进入工作舱」回 v7。
10. 全程 `.crew` 恒为 344×540（1440）；1280 / 1024 / 860 无横向溢出、无 console error。
