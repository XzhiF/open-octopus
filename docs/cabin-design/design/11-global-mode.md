# 11 · 全局模式：全域座舱（cockpit-v12）

> 2026-11-14 用户口径（v9 → v10 → v11 → v12）：
> ① v9 的形态对了，但**左栏是 attention、编队却在中间**——要左边直接是编队，右边就是那一条的全部；
> ② 要有**宇宙穿梭在驾驶舱里**的感觉：舱窗外得有星流；
> ③ 补上原来挤在 chat 输入框上方的东西：**选模型、看上下文、看 token 消耗**；
> ④ 补回和**虚拟形象的直接交互**，以及她**时不时主动说一句**；
> ⑤ 展开的对话要能**在上层自由移动**——有时要看某条作业的细节，再说话；
> ⑥ 再加一点**全局特效**，跟穿梭一个路子，并且**跟色调走**；
> ⑦ 浮窗要能**盖到左栏编队**，默认几何跟 v11 一样，**不透明度可调**（按 TUI 的换色习惯）；
> ⑧ 来消息**不要在提示窗里放按钮**（不用追时间点），换成**全局边框流动**；
> ⑨ **焦点进输入框**，对话框就自动展开。
>
> 总目标：在一个座舱里看到所有要的信息、完成所有任务；但任何补充都必须**简约**，
> 并且守**点 → 面**的规矩，不能把屏幕糊满。
>
> 一句话：**左栏编队（点），右面全集（面），底栏是舰桥，对话是浮窗，舱窗外是星野。**

原型：`../cockpit-v12.html`（自包含 HTML，直接打开）。
前稿：`../cockpit-v11.html`（舰桥 + 立绘交互）、`../cockpit-v10.html`（左栏编队 + 星流）、
`../cockpit-v9.html`（编队大卡）、`../cockpit-v8.html`（三栏仪表盘，未采用）。

## v10 → v11 补了什么

| 补的东西 | 放在哪 | 为什么这么放 |
|---|---|---|
| 选模型 + 推理强度 | 指令条上方一条**舰桥仪表条**（`◇ Opus 5.5 ▾`），点开一枚小浮层 | 模型只影响对话；它属于「下指令」这条线，不属于编队 |
| 上下文占比 + token ↑↓ + 本舱消耗 | 同一条仪表条（`◉ 42% 上下文`、`↑ 12.4k ↓ 3.1k`、`¥1.28`），点开「上下文与消耗」浮层 | 原来在 chat 输入框上方，现在收成一行读数；细节进浮层 |
| 和立绘的交互 + 画廊 + 在场 | 点汐音立绘，头顶弹一条**控制条**（说一句 / 互动 / 7 个表情 / 在场频率） | 贴着她，不占面；关掉就回到原样 |
| 她主动说一句（在场） | 角色对白 + ticker，**不进 chat** | 不污染 transcript、不花 token |
| 舱筛选 | 编队栏内的 `全部 / 账务 / 网关 / 风控` 小胶囊 | 3 个舱一眼可切；切舱自动落到该舱最紧要的一条 |

## v11 → v12 补了什么

| 补的东西 | 怎么做 | 规矩 |
|---|---|---|
| 对话可在上层自由移动 | 通讯层从「整块盖住面」改成**固定浮窗**：拖标题栏可以放到舱里任何位置——包括左栏编队上方；右下角改大小、`—` 收起成一条、`📌` 锁定位置 | 换作业 / 换页签**不会关它**，可以一边看运行细节一边回话；越界自动夹回视口 |

| 不透明度可调（TUI 式） | 标题栏 `◍ 94%` 五档循环：94 / 82 / 70 / 55 / 100；也可说「透明」 | 只调底板与模糊，**文字保持实色**；档位本次会话记住 |
| 聚焦即展开 | 输入框一拿到焦点，浮窗就打开；已经收起（`—`）就摊回原大小 | 不用再点 ticker 或 ⌘K |
| 作业头收口 | 五个页签移到标题行右上；第二行只留分支 / 正在做什么 / 元信息 / 动作 | 右上不再留空，正文多出约 80px |
| 来消息只报信 | 简报窗去掉「看全集」按钮，10 秒自动收起；同样的信息已经在编队行、ticker 和 chat 里 | 不要求当场点击，不用追时间 |
| 全局特效跟色调 + 舱壁流光 | 星流、跃迁环、中心闪光、彗星、来消息脉冲全部取当前色调的 `--a` / `--b`；到达时屏幕四边再走一圈流光（用这条 attention 的颜色）；换色调时直接跃迁一次 + 一圈脉冲 | 只在背景与缝里，不压字；减少动效时关闭 |

## 壳：v6 的五件东西原样保留

1. **左栏只有一件事**：v11 是编队（见下）。
2. **汐音大立绘常驻**：底部左下，344 × min(60vh, 548)；随状态换表情，头顶漫画对话框打字机，
   名字右侧一行**情绪标签**（待命 / 调度中 / 推演中 / 满意 / 担心 / 提醒 / 俏皮）。
   v11 起**立绘可点**。
3. **安静层**：收起面时只剩任务钟 + 四个读数 + 一句提示。
4. **通讯层**：`⌘K` / 点 ticker 展开；与面共用同一块内容区；可钉住；关掉不丢。
5. **底部指令条 + 回执 ticker**：所有动作仍然是一句话；卡片按钮只是兜底。
   v11 在 ticker 与输入框之间加了 24px 的**舰桥仪表条**。

### 左栏 · 编队（点）

- **舱筛选**：`全部 / 账务 / 网关 / 风控`（带条数）；切到某舱时，若当前面不属于该舱，自动换成该舱最紧要的一条。
- **分组**：`需要你`（wait / blocked，含 attention）→ `运行中` → `排队` → `已完成`。
- **一行一条作业**：① 类型字形 + 名字 + 右端状态；② 舱色点 + 舱名 + 正在做什么。
- 行高约 52px；8 条作业在 900px 高的屏里全部可见。
- 选中态：左侧 2px 强调色 + 微光底；`↑↓` 换一条、`⌥1` 回到最紧要的一条、`Esc` 收起。
- 窄屏（≤1120）：左栏收成可拉出的浮层，HUD 出现「☰ 编队」。

### 右面 · 作业全集（面）

头部：类型、名字、状态、舱 · 执行者 · 用时 · 消耗 + 关闭；第二行是分支 / 正在做什么 / 主操作。

| 页签 | 内容 | 版式 |
|---|---|---|
| 概览 | 汐音 ↔ 作业时间线 + 状态四格 + AC / 节点 / 变更计数 + 汐音一句话 | 左时间线，右状态 |
| 对接 | 你 ⇄ 汐音 ⇄ 执行者三方同屏；执行者的话只作回执 | 单列大消息流 |
| 运行 | 节点竖排（✓ / ● / ✕ / ○）+ 选中节点实时流 + 节点产物；拍板选项独占一条横幅 | 节点 + 流 |
| 变更 | 提交 + 文件 + diff，点文件切换 | 文件 / diff |
| 验收 | AC 清单（✓ / ! / ✕）+ 证据四格 + 通过 / 打回 | 清单 + 证据 |

- 页签是**同一扇窗里的段**；任何时候只有一扇面。
- 通过 / 打回后，该行移入「已完成」，**自动落到下一条要你的作业**。

## 舰桥：底栏仪表条（选模型 / 上下文 / 消耗）

位置：ticker 与指令输入之间，高 24px 的一行读数——这是「驾驶舱的仪表条」，不是第四个面板。

```
◇ Opus 5.5 ▾ │ ◉ 42% 上下文 │ ↑ 12.4k ↓ 3.1k │ ¥ 1.28 本舱            ◉ 在场 · 标准
```

- **`◇ Opus 5.5 ▾`** 点开**心智浮层**：Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / 自动选，
  每条带一句说明 + 窗口 + 单价；底部是推理强度（低 / 中 / 高）。
  规则：**只影响汐音的对话**；作业里的执行者按各自配置跑。`⌘⇧M` 循环切换。
- **`◉ 42% 上下文`** 点开**上下文与消耗浮层**：
  - 84k / 200k + 已用 42%；
  - 构成条：系统 12% / 历史 64% / 工具 18% / 记忆 6%（堆叠色条 + 图例）；
  - 本舱按主体用量：汐音主对话 / ledger-2 / gateway-1 / gateway-2 / ledger-1 / 对话 Agent，
    每行一根条 + ¥；合计 = 顶栏那个 ¥1.28；
  - 动作：**压缩上下文**（原型里 42% → 22%，汐音回一句，ticker 记一笔）。
- **`↑ / ↓`** 是本轮 token；**`¥`** 是本舱今日。
- **`✦ 汐音舰长`**：舱主对话的固定身份，跟在模型 / token 后面（只读）。
  原来它在 composer 下方单独占一行；2026-11-14 用户口径：搬进舰桥，底栏不再多一行。
- **`◉ 在场 · 标准`**：一眼看到她在不在场；点一下开关。
- **浮层规矩**：都从对应的读数向上弹、贴住按钮、点外部 / `Esc` 即收；
  宽度 334 / 392，不盖整屏、不改变面的状态。**点 → 小面**，不是第三个层级。

## 汐音：立绘交互与在场

- **点立绘**，头顶弹出一条 344px 的**控制条**（不挡面，不盖她的脸）：
  - `✦ 说一句`：立刻让她说一句（事实优先，见下）；
  - `♡ 互动一下`：随机一句反应 + 换表情 + 一颗心飘上去；
  - **表情画廊**：7 个小圆像（待命 / 调度 / 推演 / 提醒 / 满意 / 担心 / 俏皮），点谁换谁，当前高亮；
  - **在场频率**：安静（25–50s）/ 标准（12–24s）/ 活跃（6–12s）——原型按秒跑。
- **在场（随机主动反馈）**：
  - 话术**事实优先**：需要你（最高优先，指向具体作业和页签）> 运行中 > 回流队列；第 3 次夹一条闲聊。
  - 闸门：页面在前台、你 **6s 没动键鼠**、没在输入、通讯层没开、立绘菜单没开、模式说明 / 入口弹窗没开。
  - 只出现在**角色对白 + ticker**，**不写进 chat**（不污染 transcript、不花 token）；
    回流和阻塞照常举牌，不受在场开关影响。
  - `现在说一句` 不受闸门限制。
- 立绘 hover 有微光；点开关闭。

## 安静（Esc / ⌥2）

收起面就回到 v6 的安静层：大任务钟、四个读数、「没有要你决定的事 · 汐音在盯着」。
编队仍在左栏；`⌥1` 或点任务钟再摊开。

## 通讯层：可移动的对话浮窗（⌘K / ticker / 聚焦输入框）

- **默认就是 v11 的那块内容区**：立绘右侧、从舱面顶到底（宽 = 舱面减立绘让位，高 = 舱面满高），
  第一次打开不需要摆位置；之后拖过 / 缩过就按你的来。
- **是一个固定层，可以放到任何地方**：拖标题栏能盖到左栏编队上方，右下角拖角改大小，
  `—` 收起成一条，`✕` 关闭；越界自动夹回视口。
- **不透明度**：标题栏 `◍ 94%` 五档循环（94 / 82 / 70 / 55 / 100），底板透、字不透；
  也可以说「透明」。
- **聚焦即展开**：输入框一拿到焦点就打开；收起状态下也会摊回原大小。
- **底栏是 v12 的单行 54px**：`❯` 输入 + `＋ 挂载` + 发送；模型 / 上下文 / token / 身份
  都在舰桥那一条，输入框下面不再有第二条控件条（2026-11-14 用户口径）。
- **用户输入历史是「索引」不是「竖杠」**：浮窗右侧收起态只留一个 `≡ N` 小把手，
  悬停 / 聚焦展开提示词列表并跳轮。classic 那边仍是一竖排短杠；全域窄浮窗里
  一杠对一轮会被读成正文旁边的又一列内容（2026-11-14 用户口径）。
- **换面不关窗**：点编队换作业、切页签、按 `⌥1`，对话都留在原地——这正是「看细节再说话」。
- **`📌 钉住` = 锁定位置**：锁定后拖动会提示先解锁；关闭窗口不解除锁定。
- `Esc` 逐层收：先收浮层 / 立绘菜单 / 弹窗，再收对话浮窗，最后收面。
- 所有动作仍可只回一句：通过 / 打回 / 接管 / 600 / 900 / 看 M1 / 编队 / 安静 / 跃迁 /
  换模型 / 压缩 / 透明 / 静默 / 在场。

## 舱窗：星流与跃迁（v10 已有，v11 保留）

- **星野**：全屏 canvas，300 颗带 z 深度的星从中心向外流，画成拖尾；另有一层不动的星尘，
  静止时窗外也是星空。
- **巡航**：速度很低，像悬停；**换面 / 收起面 / ⌥W / 指令「跃迁」**：星流加速拉成线，
  一圈跃迁环从中心扩出去（<1s）。
- 星流只在面的缝隙里，不压字；`prefers-reduced-motion` 下近静止、隐藏跃迁环。
- **跟色调走**（v12）：星点、跃迁环、中心闪光、彗星尾、来消息脉冲全部取当前色调
  （`--a` / `--b`）；换色调时自动跃迁一次 + 一圈同色脉冲。
- **彗星**：每隔 7–17s 有一颗从舱窗外划过，尾巴是当前色调的渐变，头点白。
- **来消息脉冲**：回流到达时，从画面中心荡开一圈（用这条 attention 的颜色），
  和右上简报卡、编队行滑入同时发生。
- **舱壁流光**：同一时刻，屏幕四边走一圈光（上下与左右各一道，用这条 attention 的颜色），
  只擦边缘、不压中间的字。
- **简报只报信**：右上简报卡没有按钮，10 秒自动收起；同一信息在编队行、ticker、chat 里各有一份，
  所以不用当场点任何东西。

## 入口与退出

- **入口**：作战舱 classic 舱面右上角「⛶ 全域」。**classic 一行不动** —— 编队行点击仍是原作业详情窗，
  全域与 classic 是两套独立界面，只靠这一个按钮单向切换（全域里「← 返回作战舱」回来）。
- **深链**（已落地）：`/cabin/:cabinId/cockpit?job=<jobId>&tab=<overview|relay|run|changes|accept>`；
  合成任务行用 `?task=<taskId>`，无 job_id 的 attention 用 `?attn=<attentionId>`；
  跨舱查看时追加 `&cabin=<归属舱>`（`cabinId` 永远是入口舱）。
- **退出**：本页「← 返回作战舱」；或 `Esc` 逐层收（浮层 → 立绘菜单 → 弹窗 → 浮层编队 → 面 → 对话）。

### E2E 环境

- `playwright.config.ts` 的 `webServer` **只起 Vite**；后端必须已在
  `OCTOPUS_SERVER_URL ?? http://localhost:3001` 上运行。后端不可达时新 spec 全部 `test.skip`。
- 默认端口（主仓库 3000）若被一个**早于 `app/cockpit/` 创建**的长驻 Vite 占着，它的 CSS
  `@import` 解析器可能保留对 `./cockpit/index.css` 的负缓存（请求 `/app/globals.css` 会返回
  postcss ENOENT）。重启 Vite 即恢复；不动长驻进程时可以另起一个新鲜 Vite 并设置
  `OCTOPUS_E2E_WEB_PORT=<port>`（`playwright.config.ts` 的向后兼容覆盖，默认行为不变）。
- 整套 e2e 有历史遗留红：`e2e/tests/auth.spec.ts` 打 `/login`，本 SPA 没有登录页。
  收尾闸门只跑新增 spec，**不以「整套 e2e 全绿」为验收条件**。

## 实现顺序（历史计划，S1–S10 已执行）

1. **原型评审**：`cockpit-v11.html`（本稿）。
2. **入口 / 编队 / 面**：按 v10 的步骤落（入口 → 编队聚合 → 概览 / 对接 / 运行 → 变更 / 验收）。
3. **舰桥**：先接模型目录与当前模型（读写都走既有 session 设置）；再接上下文构成与消耗读数。
4. **立绘菜单 / 在场**：表情与话术全是前端；在场只写 ticker 与气泡；频率与开关进本地设置。
5. **对话浮窗 / 特效**：浮窗是固定层 + 拖拽 / 缩放 / 不透明度（无数据）；默认几何由舱面与 `.scene` 的
   `padding-left` 算出，和 v11 对齐；特效取 CSS 变量，换色调时刷新调色板。
6. **验收**：三舱各一条真实作业跑通「编队 → 全集 → 页签 → 动作 → 回写」，并在 1440×900 下核对留白；
   再核 1280 / 1024：默认浮窗与面同高、无横向溢出、聚焦输入框能展开。
