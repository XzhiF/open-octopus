# 15 · 新建作战舱 v2：一列，一件事

> 原型：`docs/cabin-design/cabin-new-v2.html`（自包含，直接打开）
> 状态：**设计稿**。v1（`cabin-new-v1.html` / `design/14`）被否，留作对照。
> 现有实现：`CabinDraftPane` → `CabinNewForm`（名称 + 目录 + org/仓库 + 需求备注的单页表单）。

---

## 0. 用户原话（2026-11-15，逐字）

> 你这个也太复杂了，我要简约的，并且它初始化的话，其实是正儿八经通过 chat 来询问我的，所以这我甚至可以什么都不选，然后进去让它再进行初始化。好吧，我这边可能就是直接新建，然后的话点开始，或者说我可以勾选啥，但是我真正确认之后呢，就是那真的会创建一个会话的，它不像新建任务必须说完话才行。好吧，再设计一下这个太复杂的界面了。我这里要简约，你知不知道啊？像我现在的做建仓设计就是非常的简约，OK, 遵循这个原则，再设计一版吧

**一句话**：这一屏不负责"谈需求"，只负责**把舱开出来**；需求、仓库、要做什么，都是进去之后汐音在对话里问的事。

---

## 1. 被否掉的是什么

| v1 的部件 | 判断 |
|---|---|
| 三栏（汐音 / 舱面 / 对话） | 太重。开一个舱不需要办公桌，只需要一张卡 |
| 侧栏立绘 + 引导语 + 记忆 + 三行对照 | 装饰性信息挤占了主操作 |
| "说话即填写"的解析器 | 概念对，但把"填表"变成了"写小作文"，与"简约"相反 |
| 底部三步进度 + 可停下 | 真实 init 本来就走 SSE 进度，屏幕上不必再造一个 |
| 常驻对话面板 | 真正的对话在舱里 —— 这里再放一个就是两个对话 |

**留下的判断**（v1 里对的部分）：一屏、没有下一步、只有一个闸门、目录已是舱就直接接进去。

---

## 2. 唯一的规则

> **表单只负责开舱；初始化在舱里的对话中发生。**

这条规则把 v2 压缩到三个元素：

1. **目录** —— 唯一必填。一个目录 = 一个舱，是身份。
2. **舱名** —— 可留空，留空取目录名。
3. **开始创建** —— 点下去就真的建舱、起主会话。

仓库、需求是**两个可勾选项**（勾了才展开一行，不勾就是两行文字）。其余问题一律后置。

### 代码上为什么成立

`CabinInitService` 的门禁 1–6（目录可写 / git / 克隆仓库 / 主线分支 / `.cabin/` 骨架 / 需求落盘）都是**确定性调用，不过 LLM**；需求为空时落盘的是：

```md
# 需求

（待补充）
```

门禁 6 照样通过。门禁 7「首迭代提案」才是**舱主会话里的一轮真实 agent**：读 `.cabin/requirements.md`，提出 M1 目标与首批任务建议（只提案，不派发）。

所以"什么都不填就进去、让她在对话里问"，不是设计上的妥协，**就是当前后端已有的行为**；v2 只是不再在开舱前假装把这件事做完。

- 一列 `min(536px,100%)`，**顶部锚定**（`padding-top: clamp(48px, 26vh, 250px)`）：勾选可选项时卡片只往下长，上面的小像和台词不动；

- ≤620 收窄：小像 64px、按钮整行宽。

**元素预算**（改稿时守住这条）：1 张像 · 2 句台词 · 3 行卡 · 2 个勾选 · 1 个按钮 · 1 行页脚。

## 4. 汐音在这里只做一件事：表明"这是开舱"

不做侧栏、不做对话面板、不做逐字动画。她只有：

- **一张 84px 小像**（`crew/xiyin-*.png`，按画面选图），表情跟着状态换：待命（微笑）/ 提醒（抬手指人）/ 建舱中（键盘）/ 完成（握拳）；
- **两句台词**：一句结论、一句解释。台词的文案就是状态的语义：

| 状态 | hi | sub |
|---|---|---|
| 空 | 选个目录，我们就有舱了。 | 目录是唯一必填 —— 其余都能进去再聊。 |
| 选了目录 | 「极光舱」。 | 点开始，我就把舱建起来，然后在里面等你。 |
| 目录已是舱 | 这个目录我认识 —— 已经是「账本舱」了。 | 不用再建一个，直接接进去。 |
| 建舱中 | 正在落舱…… | 写 .cabin/ · 接仓库 · 起一条会话。 |
| 完成 | 舱建好了。 | 第一句我来问：这个舱你打算长期拿它做什么？ |

跟新建任务 / 新建会话的区别只有这一处，但它足够：**任务和会话没有脸，舱有**。

## 5. 状态机

```
draft
 ├─ 选目录（抽屉：上次 / 常用 / 手填，← 一次点击）
 ├─ 起名（可留空，右侧灰字显示"将采用 <目录名>"）
 ├─ 勾 绑仓库 → 展开 chips；勾 先写一句需求 → 展开两行 textarea
 ├─ 直接点开始、目录为空 → 不发请求：抖一下目录行 + 她说"得先有个目录" + 展开抽屉
 └─ 目录已是舱 → 行下亮一行提示，按钮变「接进「账本舱」」
creating：按钮 disabled + 文案「正在落舱…」/「正在接入…」，她换表情
done：卡片原地切成完成态（同一块地方，不跳）
      · 舱名 + 已创建 / 已接入「X舱」
      · 目录
      · 「进去之后她会问」三条
      · [ 进入作战舱 → ]
```

**闸门**：`draft` 期间零写请求；只有「开始创建 / ⌘⏎」进 `creating`。取消（← 对话）什么都不留。

## 6. 字段 → 真实 API

| 界面 | 取值 | 实现 |
|---|---|---|
| 目录 | 必填 | `createCabin({ path })`；冲突 → `attachCabin(path, name)` |
| 舱名 | 可空 | 空 → `basename(path)` |
| 绑仓库 | 可空 | `org`（默认当前 org）+ `repos[]`；不勾 → 都不传 |
| 先写一句需求 | 可空 | `requirements`；不勾 → 不传，门禁 6 落 `（待补充）` |
| 开始创建 | — | `createCabin` → `initCabin(id)` → `onCreated(id)`，壳里打开 `main_session_id` |
| 完成态「进入作战舱」 | — | 与现有 `CabinNewForm.onCreated` 同一个出口 |

**与现有 `CabinNewForm` 的差**：它要求名称 + 目录都非空；v2 只要求目录。名称校验从"必须填"降级为"留空自动取目录名"——这是本稿唯一的接口语义变化。

---

## 7. 交互细则

| 事件 | 行为 |
|---|---|
| 点目录行 | 抽屉：4 个记住的路径（带「上次 / 常用」标）+ 手填输入，`Enter` 即用 |
| 点「开始创建」但没目录 | 不发请求；抖一下 + 台词换成"得先有个目录"+ 自动展开抽屉 |
| 勾「绑仓库」 | 展开一行 chips（`workspace / ledger / engine / web-app / docs`，可多选），再点收起 |
| 勾「先写一句需求」 | 展开两行 textarea；不填也算勾了（不阻塞） |
| 目录已是舱 | 行下亮提示 + 按钮变「接进「X舱」」；点击后完成态显示"已接入"而不是"已创建" |
| `⌘⏎` / `Ctrl+⏎` | 开始创建（唯一闸门的键盘等价） |
| `Esc` | 收起目录抽屉 |
| reduced-motion | 关闭扫描线与抖动动画，其余不变 |

## 8. 落地建议（改 `CabinNewForm`，不动别的）

1. **去掉必填校验的名称**：`name.trim() || basename(dir)`；输入框右侧常驻灰字提示将采用的名字。
2. **org/仓库 / 需求默认收起**：两个 checkbox 控制展开，默认不展开；不勾就不传字段。
3. **不在此处渲染 init 进度**：`initCabin` 后直接 `onCreated(id)` 进舱；进度本来就在舱主会话 / SSE 里。
4. **保留 attach 分支**：现有 `catch { attachCabin }` 已对齐，只需把按钮文案与完成文案区分开。
5. 页面骨架可直接复用 `CabinDraftPane`（它已经是 `items-start` + 居中的 `max-w-xl`），把 `CabinNewHero` 的大标题压成 v2 的"小像 + 两句"。

## 9. 验收

1. 打开即见：小像 + 两句 + 目录 / 舱名 / 两个勾选 / 一个按钮；**没有弹窗、没有下一步、没有第二列**。
2. 只选一个目录 → 点开始 → 真的建出舱（`POST /api/cabins` 1 次）并起会话；进入后主会话里有门禁 7 的那条 agent 提议。
3. 名称留空：舱名 = 目录名，无报错。
4. 目录已是舱：按钮文案变「接进「X舱」」，点击走 `attach`，不新建第二个。
5. 未选目录点开始：**零请求**，她说缺目录并展开抽屉。
6. 勾选 / 取消可选项：卡片只向下生长，小像与台词 rect 不变。
7. 完成态与草稿态同高（318），按钮位置不变。
8. ≤620px：按钮整行宽、卡不溢出、抽屉不遮住输入框。

## 10. 遗留

- **立绘文件名与画面不对应**（`idle`=抬手指人、`thinking`=大笑、`wink`=全息键盘、`cheer`=睡着…，见 `design/14` §10）。v2 用 `FACE` 表按**画面**挑图；实现时若直接 `moodPortrait(mood)` 会错位，需重命名或加映射。
- 「记住的目录」目前是原型硬编码；真实实现应来自 `GET /api/cabins`（已有舱）+ 最近一次 `browseDirectories` 的选择。
- 目录选到「已有 `.cabin/` 但未注册」的目录：现在会走 create 失败 → attach，结果正确，但没有提示"我是从残骸里接回来的"。
- 要不要在按钮旁给一个"只建空舱、不跑 init"的次选项？（后端的 `init` 本来就是可选的一步。）
