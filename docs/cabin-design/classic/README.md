# classic · 双模式（出舱 / 进舱）

`index.html` 一个文件演示两种模式与过渡：

**舱外 · classic** —— 和现网同一风格：左栏「作战舱 / 任务 / 会话」+ chat。
点作战舱行的「进舱 →」进入沉浸模式，带一次 warp 过渡。

**舱内 · 沉浸** —— 默认只有四样东西：
- 汐音的立绘（含待办小 chip）
- 一条编队（每类作业一个圆角 tile，状态点 + 进度环）
- 一条指令条（`❯ 下令…`，派发/问编队/处理待办）
- 顶部三个数字（运行 / 等你 / 消耗）

没有常驻面板、没有文字墙、没有按钮矩阵。

按需展开：
- 点编队 tile → 右栏「现场」滑出（按作业类型给最短现场：工作流、直做、工作流开发、子代理、外部 agent）。
- 点 ✉ → 通讯层，chat 只在需要时拉开。
- 顶部「出舱」或 Esc → 回到 classic；当前会话不变。

**宗旨**：chat 已经信息很重，舱内只留调度所需，其余一律按需。
舱内是 cockpit-v5 的收敛版：去掉常驻面板与说明文字，只留角色 + 编队 + 指令条。
