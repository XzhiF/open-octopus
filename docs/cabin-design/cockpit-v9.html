两级
编队（点）3 个舱的并行作业同一张卡：类型 / 舱 / 状态 / 进度 / 谁在做。点一张，开它的全集。
作业全集（面）概览 / 对接 / 运行 / 变更 / 验收五个页签，同一扇窗里看完，不跳走、不再开第二个窗。
场

通讯层⌘K / 点 ticker 展开；与编队共用同一块内容区，可钉住；关掉不丢。
在场汐音立绘随状态换表情（调度 / 推演 / 满意 / 担心），头顶对白与 ticker 同步。
回流模拟回流：attention 落左栏、编队卡变「等你」、简报卡滑入，点开直达对应页签。
入口 / 退出
从作战舱进入舱面右上「⛶ 全域」；⌥G。旧舱面与舱内会话不动。
退出「← 返回作战舱」或 Esc 先收编队、再收对话。
规则：一次只开一扇面；左栏永远在。编队是唯一索引，面是这一条作业的全部； 动作仍然回落到一句对话（通过 / 打回 / 接管 / 600），按钮只是兜底。
