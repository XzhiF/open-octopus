# 全局三栏外壳：左导轨 + 内容区 + 右作业坞，对话页取代 Dashboard 成为首页

现状 web-app 是「薄外壳 + 胖页面」：`AppShell` 只提供顶栏与滚动容器，全站导航是 `header.tsx` 里一条横向数组（Dashboard `/` 居首），每个页面自管列布局。原型 `octopus-ai-native-proto/index.html` 给出驾驶台式布局：左导轨、中央视口、右作业坞，并以「对话」为首屏。owner 要求按原型调整项目布局、新增对话菜单替代 Dashboard，同时保留当前暗色 TUI 风格。硬约束：已有聊天实现（Agent 会话栈、任务草稿工作台）必须复用，不重造。

## Decision

- **全局三栏外壳**：`AppShell` 改为「左导轨 + 内容区 + 右作业坞」，所有路由共用。页面内部现有布局（知识中心左树/右栏、任务运行台右栏、工作空间三栏）不动，作业坞可收起作为腾挪手段。
- **左导轨**：默认 208px、收起 56px；分「工作 / 资产 / 系统」三组——工作 = 对话（`/`）/ 今日（`/dashboard`）/ 任务看板 / 工作空间 / Agent；资产 = 知识中心 / 资源 / 系统调度；系统 = 系统管理 / 设置。设置从顶栏移入系统组，顶栏保留 logo 与通知。宽度记忆偏好；<768px 导轨改为 `Sheet` 抽屉。
- **对话页**：`/` 成为默认首页，复用现有 Agent 会话栈（`useAgentSessions` + `useAgentChat` + `ChatArea`），左列只列 Agent 会话；另给「新建任务草稿」入口直开既有 `TaskModal / AuthoringWorkspace`，草稿不进入对话页会话列表。v1 不搬原型的任务线程、MoA、成本台账、上下文右栏。Agent 页去掉重复的「对话」标签，只留记忆 / SKILL / 分身 / 配置；`/agent?tab=chat` 重定向 `/`。
- **Dashboard 迁址**：原页面迁至 `/dashboard`，菜单名与页内标题改为「今日」，副标题保留「工作流编排平台概览」；logo 指向 `/`（对话）。
- **作业坞**：默认 240px，可拖 200–360px，收起 44px 图标条；宽度/收起态 localStorage 记忆；<1024px 隐藏，1024–1280 默认收起。「导航」区 = 本次会话 MRU（按 pathname 去重、排除首页、最多 4 条、不跨刷新持久化；点击跳转，可移除）；「作业」区 = 状态为 `running / paused / awaiting_review / archiving` 的任务，最多 5 条，点击经 `/tasks?task=<id>` 深链打开既有详情，用 `/api/tasks/events` 刷新；空态指向任务看板。不做成员生命周期、悬停卡、已完成组。
- **视觉边界**：沿用当前暗色 pop TUI token 与组件语言；不引入原型的天海渐变、亮暗主题切换、底部状态栏。顶栏保留现有 56px 结构，仅移除横向导航。

## Considered Options

只在对话页做三栏：不构成全局布局，与原型及 owner 目标不符——弃。完整复刻原型任务线程工作台：需要新的线程/未读/成员模型与 API，超出本期——弃，先用 Agent 会话栈加草稿入口。用全局导轨/坞替换各页内部栏：知识中心树/右栏、运行台右栏属于页面语境，替换风险高——弃。照搬原型视觉与亮暗主题：owner 明确要求保持当前 UI 风格——弃。保留 Dashboard 在 `/`、对话放 `/chat`：与「对话替换 Dashboard 菜单并成为首屏」的目标冲突——弃。

## Consequences

- 全站导航单源从顶栏横向数组迁至导轨配置，`Header` 移除 nav；激活态沿用现有黄色贴纸语言。
- 测试面：`/` 的 Dashboard E2E 迁至 `/dashboard` 并改标题断言；header/nav、settings、system-models 的导航定位器改到导轨；知识中心 E2E 的 `page.locator("aside")` 需消除与新导轨的歧义；截图基线需重录。
- 知识中心、工作空间详情、任务运行台在坞展开时变窄，靠坞收起兜底；若实测过挤，再评估「已有右栏的密集页默认收起坞」的路由感知策略。
- 聊天入口收敛为唯一：对话页是主 Agent 会话入口，Agent 页回归管理面。
- 作业坞数据依赖 `/api/tasks/events` 与 `/tasks?task=` 深链；MRU 为客户端会话态，不新增服务端表。
- 新增术语「对话页 / 今日页 / 作业坞 / 导航记录 / 作业」登记于 GLOSSARY-MAP。
