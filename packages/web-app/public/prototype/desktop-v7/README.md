# Octopus Desktop v7 — 综合体

> 目标：把 v1 的「快捷直达 + 内容丰富」和 v6 的「安静皮肤 + 单体应用感」合体，
> 并干掉最后那层入手门槛——「自己管窗口」。
> 纯静态原型：无构建、无依赖、假数据。打开 `index.html` 即用（建议 1280+ 宽）。

## 相对 v6 的四个内核变化

1. **吸附分屏（dock engine）**
   拖标题栏到屏幕边缘即对齐：左右半屏、上下半屏、四角象限（预览带中文标签 + 顶替提示）。
   吸附后的窗口零间隙、直角贴边——桌面天然被填满。拖离即恢复浮动。
2. **分隔条（divider）**
   左右（或上下）成对吸附后，两窗之间出现一条可拖的线：拖动实时按比例重排两窗，
   比例（frac）持久化到 localStorage。象限布局为 50/50 静态，避免过度约束。
3. **子窗口层次（child windows）**
   任务详情 `⧉ 浮出`、运行日志 `⧉` 会从父窗「长出来」：三级堆叠阴影 + 标题栏左侧
   accent 条纹 + `↳ parent` 面包屑；子窗聚焦时父窗链退暗（is-dim）。
   父子同拖（子窗跟随位移）、父窗最小化/关闭连带子窗、`esc` 收聚焦子窗回父窗。
   父窗头部出现 `⧉ N` 徽标，点击直达最深的子窗。
4. **一键填充（⌥T / tile / 底栏「⌗ 整理」按钮）**
   1→左半 · 2→左右 · 3→左+右上+右下 · ≥4→四象限。全部走同一 dock 引擎，
   填完即出现可拖的分隔条——「Tile」第一次真正叫「填充」。

## v7b 增补（按用户反馈）

- **八向边缘调大小**：浮动窗口四边 + 四角共 8 个隐形 resize 手柄（hover 出现 accent 提示），
  不再只有右下角一点。吸附/最大化时手柄自动隐藏（吸附对用分隔条调）。
- **底栏窗口 tab 条（taskbar）**：当前桌面 + 全局 agent 的每个窗口一枚 chip——
  图标 + 名 + 吸附区标记（L/RT/RB）+ 子窗计数（⧉N）；点击直达、hover 出 ×、
  聚焦高亮、最小化半透明。**Ctrl+Tab / ⌥Tab（⇧ 反向）像切标签页一样循环切窗**。
- **一键整理按钮**：底栏「⌗ 整理」（= ⌥T），不藏快捷键里。

## v7c 增补（workflow 关键视图 + 多任务）

- **按节点日志**：RUNS 的 LOGS 页新增节点过滤 chips（◍ ALL · plan · build · test…，
  带计数与状态字形）；每行日志前挂 `[node]` 标签；**点 GRAPH 里任一节点 = 直接过滤到它的日志**；
  live 流按当前运行节点归组，过滤态下只进匹配行。
- **HARNESS 监控面板**（rail 第 4 格 ⌥4 / `open harness`）：
  顶部 4 卡（护栏 3/3 · 24h 拒绝 12 · 风暴 0 · 预算 92%）→
  RUN GUARDS 表（风暴/边界/循环/预算 四护栏状态 + 调用速率 + **cancel/deny/other 三色 kinds 条**）→
  A/B LEDGER（strip-env 证伪 · toolDenialKind 已证实 · P4 验证中——与仓库记忆一致）→
  事件流 live tail。
- **>4 窗口的一键整理**：改走「分排铺满」网格（5 窗 = 3+2，每排均分整行宽，100% 覆盖零空隙），
  toast 报形状；≤4 仍走具名象限（有分隔条）。
- **Mission Control = 多任务切换**：⌘⇧M 视图每卡左上角序号徽章、悬停浮出摆位动作条
  `◧ ◨ ⬒ ⬓ 浮 ─ ×`——左半/右半/左上/右下/转浮动/最小化/关闭，点完**留在视图里连续操作**；
  卡片含跨空间全部活窗口（everything stays alive）。
- rail 变 9 格：⌥1…⌥9（HARNESS 占 4）。

## 保留（v6 → v7）

- 安静 Codex 皮肤：中性面、无衬线正文、等宽只给数据、明暗双版（`theme light|dark`）
- rail ⌥1–8 直达、底部控制台、⌘K 面板、⌘J 主 Agent、⌘⇧M Mission Control
- space 下拉切换、窗口几何/吸附状态跨刷新持久化（`octopus.desktop.v7.*`）
- 关闭 ≠ 取消任务（视图与持久状态分离）

## 新增控制台命令

```
dock L|R|T|B|LT|RT|LB|RB   聚焦窗口吸附到指定区
undock                     聚焦窗口脱离吸附
fill                       tile 的别名
term [run-id]              浮出当前 run 的日志子窗
```
