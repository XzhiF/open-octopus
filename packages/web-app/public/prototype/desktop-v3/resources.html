Distinctive, production-grade frontend interfaces with high design quality.

group: design source: agency-agents-zh v2.3.0

When to use

Use when the user asks to build web components, pages or applications and visual direction matters as much as code quality.

Principles

  • Commit to a clear visual direction before writing components.
  • Typography carries hierarchy; avoid default browser rhythm.
  • Motion is a signal, never decoration. Respect reduced motion.
  • Every surface needs a reason: border, elevation or spacing.
