Octopus · desktop v1

Quiet desktop.
Durable context.

不是把 Web 页面塞进一个更窄的壳。是把「页面导航」换成「窗口工作台」：窗口是耐久状态的视图，关闭只释放视图，不销毁运行。

01
Context is the product切换 space 不应清空屏幕。至少保留 3–4 个活跃窗口，以及最小化 shelf。
02
Quiet by default近黑石墨、一层暖骨色强调、1px 发丝线。颜色只标记状态，不装饰。
03
Window, not page工作流、运行、对话、验收各有生命周期。可以并排、可以最小化、可以重开。
04
Data in mono, prose in sans时间、token、成本、ID 使用等宽数字。叙述与标题保持人文节奏。
05
Native first同一套窗口模型可映射到 Tauri/Electron：先做应用内窗口，再可选 detach 成 OS 窗口。
