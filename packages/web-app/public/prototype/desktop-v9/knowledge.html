concepts/desktop/window-model

Window model

A window is a view over durable state — never the state itself. This is the rule that makes a multi-window desktop feel safe instead of fragile.

stable confidence 0.93 compiled 12m ago design

Core rule

Navigation must never destroy context. Opening a run, a task or a conversation creates a window with its own lifecycle. Closing the window releases the view, not the underlying execution, stream or scroll model.

Invariant
Closing a window must not cancel a run. Reopening it must restore cursor, tab and scroll state from the durable store.

Three layers

  • Scene presets — each space opens with a curated arrangement of 3–4 windows.
  • Layout commands — tile, cascade, reset, minimize all. Bound to ⌥T and the Windows menu.
  • Cross-window references — drag a run into chat to attach it as a context chip.

Window chrome

Each title bar carries identity, status and lifecycle controls. Only the focused window lifts; the rest stay dim and quiet. The shelf at the bottom is the durable index of everything still open.
