# 02 — Evolution Scope

Type: grilling
Status: resolved

## Question
Which dimensions of the agent should support evolution?

## Answer
Full 5 dimensions:
1. **persona** — persona.md content (role definition, principles, tone)
2. **skills** — SKILL.md definitions (instructions, triggers, steps)
3. **prompt** — Workflow prompt templates in YAML nodes
4. **system_prompt** — SystemPromptAssembler segment weights, priorities, content rules
5. **memory** — long-term.md experiences and insights

**Reason**: Comprehensive evolution requires all dimensions to be adjustable. Partial evolution creates blind spots where improvements are needed but not possible.
