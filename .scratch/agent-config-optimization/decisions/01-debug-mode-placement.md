# 01 — Debug Mode 位置重组

Type: grilling
Status: resolved
Blocked by: None

## Question

Debug Mode 开关目前放在 GeneralConfig (通用配置) 面板里，但它实际上控制的是调试日志的记录。是否应该将 Debug Mode 开关移到 DebugLogViewer (调试日志) 面板的顶部，形成一个统一的"调试"容器？

## Answer

**决定**: 将 Debug Mode 开关从 GeneralConfig 移到 DebugLogViewer 面板顶部，形成统一的"调试"容器。开关在上方，日志列表和详情在下方。
