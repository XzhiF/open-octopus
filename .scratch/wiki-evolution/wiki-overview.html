1三层架构（层契约）

写路径只有一条：入队 → 全局 FIFO + wiki 根锁 → 唯一写闸编译 → 一次编译 = 一个 git commit，失败原子回滚零半成品。读永不锁。

2代谢闭环（P4 全景主图）

库的「用 → 记 → 判 → 改 → 退 → 恢」全循环。红字为不可让步的闸：除窄口外一切变更必经人裁；一切写经队列串行位。

4共演公式（SCHEMA.md · 人机两面，改权重=人改文档+同步码）

confidence = helpful / (helpful + not_helpful) —— 总记账 < 3 不刷新（保持编译期初值）
低置信入列 = confidence ≤ 0.2 且 引用 ≥ 3 ⇒ finding 人裁（修订或退役）
健康分 0-100 = clamp(0,100, 100 − Σ open severity(critical 8 / major 4 / minor 2) − Σ 越水位的页 (水位−0.8)×25)
僵尸（D3） = 最近引用逾 90 天，或从未被引用且建页逾 90 天（吃实效账目）
自动退役窄口 = 观察窗满 90 天 ∧ 两账窗内零命中 ∧ 零活页入链 ∧ 非人工文件 ∧ 带规则锚点
INDEX 预算 = 恒见部分 ≤800 token；>640（80%）放行+预警 finding；>800（100%）拒写+压缩建议
域失衡（D5） = 单页锚点占全库 >30%（全库 <10 锚不判）· 重复对（D2）= 跨页规则 jaccard ≥ 0.75（禁 embedding）
